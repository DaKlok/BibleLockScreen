//    find the `when` block that maps language codes to string instances
//    (search for `"EN" -> enStrings`), and add your case:
//         "PT" -> ptStrings
// 6. Create `app/src/main/assets/verses_XX.json` (copy verses_EN.json and

// 7. Commit and open a Pull Request. The CI validator will check your work.
