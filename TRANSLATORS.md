## Notes for contributors

- Use whatever name/handle you prefer. A GitHub username is fine.
- If you contributed to both UI strings and verse content, you can either
  list yourself once (covers both) or split the entry, e.g.:
  ```
  ## Portuguese (PT)
  - **@yourhandle** — UI strings
  - **@anothercontributor** — verse content (public-domain Almeida 1911)
  ```
- Please mention which public-domain Bible version you used for the verses.
  This helps future contributors avoid accidentally duplicating work or
  mixing versions.
